# Jemielttf Tap

## How do I install these formulae?

`brew install jemielttf/tap/<formula>`

Or `brew tap jemielttf/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "jemielttf/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
